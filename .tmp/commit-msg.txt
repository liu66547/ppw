重构：3D 改为全页背景 + 太阳/地球程序化着色器 + 技能板块玻璃拟态

一、结构重构
- 移除 300vh 首屏与三个文字浮层，页面改为完整个人介绍自上而下平铺
- 3D 画布改为整页背景（fixed + z-index:-1），滚动进度覆盖整个文档
- 组件从 index.astro 移到 BaseLayout.astro，与 .aurora 同级

二、修复移动端横向溢出（最高优先级）
- html 与 body 同时加 overflow-x: clip
- 用 clip 而非 hidden：hidden 会把元素变成滚动容器，破坏 sticky 导航
- 实测 scrollX 恒为 0、scrollWidth = 视口宽、导航 sticky 正常

三、太阳质感（程序化着色器）
- 3D fbm 米粒组织 + 随时间对流的大尺度明暗流动
- 色温分层：核心白热 -> 金黄 -> 边缘深橙红，带临边昏暗
- 菲涅尔边缘加亮形成日冕过渡，消除多边形轮廓
- 三层日冕 Sprite（4.4x / 8.5x / 15x 半径），缓慢呼吸

四、地球（程序化着色器）
- fbm 阈值 + 域扭曲生成大陆，海岸线不规则
- 极冠、独立漂移的云层、夜面城市微光
- 菲涅尔大气边缘光 + 外层大气壳（背面渲染加色）
- 月球 0.27 倍地球半径，位置固定

五、宇宙背景丰富度
- 两级星场（7200 + 2000 点），顶点着色器闪烁
- fbm 生成的丝絮状星云贴图，5 片沿黄道分布
- 黄道面扁平尘埃带（3600 点）
- 22 条静态流星余迹作为远景点缀

六、技能板块玻璃拟态
- 外层 30% 半透明玻璃 + backdrop-blur(14px)，露出 3D 星空
- 内层文字无背景色，靠 text-shadow 压住背景
- 圆角 16px、细边框、inset 内发光、悬停高亮 + 轻微上浮
- 熟练度徽章与技能标签统一为胶囊样式

七、关键 bug 修复与设计决定（都写进注释）
1. .ds-canvas 是 JS 动态创建的，没有 Astro scoped 属性，
   普通选择器完全匹配不上（实测 position 变 static、z-index 变 auto），
   必须用 :global()
2. body 不透明底色会盖住 z-index:-1 的画布，改由组件接管底色
3. 相机横穿太阳前方时太阳会瞬间占满画面（实测 58960pct），
   改为相机绕行 + 后退，朝向与距离解耦
4. 手填视线关键帧无法同时满足构图约束，改为按屏幕目标位置反解视线方向
5. 新增中部压暗阅读罩，解决正文满宽时天体必然落在某块文字后的问题

验证：3D 背景 17 项、移动端 14 项、横向滚动 4 项、
原有功能回归 80 项，合计 115 项全部通过

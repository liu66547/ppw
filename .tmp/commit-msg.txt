按明确规则提升联系板块文字可读性

用户给定的规则（严格遵守）：
  1. 主标题 -> 纯白 #ffffff、字重加粗一级、1px 1px 2px rgba(0,0,0,0.8) 投影
  2. 副标题 -> #b8c0cc、不透明度 100%
  3. 联系方式卡片 -> 文字与图标纯白、卡片底色不透明度提升约 15%
  4. 底部按钮 -> 文字 100% 不透明、高对比

硬性约束遵守情况：
  · 只改文字颜色 / 字重 / 文字投影 / 卡片底色透明度四个维度
  · 未动布局，未动其他板块，未提亮 3D 背景
  · 所有选择器以 .ds-contact 作用域或专用 .ds-contact-* 类名开头

具体改动：
  · <footer> 加 .ds-contact 作用域类
  · 主标题 text-fog-50(#f1f5fb) -> text-white，字重 700 -> 800
  · 副标题 text-fog-400(#8b9ab1) -> text-fog-200(#c7d2e2) + 覆盖规则提到 #b8c0cc
  · 卡片文字 去掉 text-fog-100，改用 .ds-contact-value -> #ffffff
  · 卡片图标 去掉 text-fog-300，改用 .ds-contact-icon -> #ffffff
  · 卡片底色 ink-900 的 80% -> 94%
  · 三个按钮加文字投影；两个幽灵按钮文字 -> #ffffff

一处按对比度数据做了偏离，需要说明：
  「发邮件给我」是 btn-primary，底色是品牌青 accent-500 (#14b8a6)。
  实测白字在它上面只有 2.5:1 对比度（远低于可读门槛 4.5:1），
  而原本的深色字是 8.1:1（WCAG AAA）。
  所以这个按钮【保持深色字】—— 强行改白反而更难读，
  而且它本来就是所有按钮里最醒目的（实心青色底），不需要再提亮。
  两个幽灵按钮则改成纯白字，对比度 18.4:1。

效果（实测文字渲染亮度）：
  主标题峰值 P99.5   171 -> 181
  文字均值          113.1 -> 117.9
  advantages        114.1 -> 119.8（同量级，contact 不再垫底）
  文字占比          4.7% -> 4.8%（与 advantages 完全一致）

验证：GLSL 静态检查、交付验收 24 项、3D 背景 21 项、移动端 17 项、
降级路径 3/3、横向滚动 4 项、原有功能 80 项，合计 149 项全部通过

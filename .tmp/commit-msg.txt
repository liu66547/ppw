修彗星尾流 bug + 重做技术栈板块

一、彗星尾流是个 bug（用户截图指出"这一大块灰褐色是什么玩意"）
   原因：尾长按 `距离 × 1.55` 计算，换算成视角约 57°~89° ——
   尾巴比整个画面还长，透视展开后糊成一大片灰褐色楔形。
   宽度系数也偏大，尾梢展开到约 700 单位。

   修法：
     尾长 1.55d -> 0.42d（视角 57° -> 23°）
     尾梢宽 ~700 -> ~150 单位
     衰减曲线改回 (1-f)^1.35，尾梢干净收掉
   现在是一个干净的锥形拖尾，不再是占屏的色块。

二、技术栈板块重做（用户："一行一行太平淡，而且暗"）
   原先是一行行平铺的 <dl>，信息对但像表格；另外它自带
   bg-ink-900/50 的 50% 深色底，把整块压暗了（和 footer 同一个问题）。

   新的设计：
     · 顶部先给结论："每天在用的技术栈" + "5 类 / 20 项 / 另了解 4 项"
     · 主体改成【分层技术栈】：每条一个 lane，左侧序号 01~05 + 分类名，
       右侧标签群；lane 之间有分隔线，形成"层"的节奏
     · 悬停时该行的强调色条从左侧长出来，整行轻微提亮
     · 标签做成玻璃小胶囊，底比页面亮一档、描边清楚，悬停转品牌青
     · "另了解"用虚线圈，刻意弱化但仍清楚可读

   亮度：
     去掉 bg-ink-900/50
     分类名 fog-50 -> 纯白（+ 细微投影压住星空）
     标签文字 fog-200 -> #e9f0fa，底色与描边各提亮一档
     序号透明度 0.55 -> 0.78
   实测文字峰值 P99.5 从 151 提到 179。

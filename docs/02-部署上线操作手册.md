# 部署上线操作手册（零基础版）

> 目标：把网站放到公网，让任何人用你的域名访问。
> 全程免费，不需要买服务器，不需要懂运维。预计耗时 40 分钟（不含域名备案）。

---

## 先理解你要做的事

```
你的电脑                     GitHub                    Vercel              你的域名
┌──────────┐    git push   ┌──────────┐   自动同步   ┌──────────┐  DNS  ┌──────────┐
│  网站代码 │ ───────────→ │  代码仓库 │ ─────────→ │  构建+托管 │ ←──── │ 阿里云解析 │
└──────────┘               └──────────┘             └──────────┘       └──────────┘
                                                          ↓
                                                    公网可访问的网站
```

**你要做的只有三件事**：

1. 把代码推到 GitHub（就像你给 `xzs-api-test` 做的那样）
2. 在 Vercel 上点几下，把仓库连起来
3. 在阿里云加一条 DNS 记录，把域名指过去

**以后每次更新网站**：改完代码 → `git push` → Vercel 自动重新部署。**不用再做任何配置。**

---

## 第 0 步：部署前必须改的 3 个地方

**这三处的站点地址必须改成你的真实域名，且保持一致。** 现在填的是占位地址
`https://liudelin.vercel.app`，如果不改，搜索引擎会把你的网站索引到一个错误地址。

假设你的域名是 `liudelin.com`（换成你自己的）：

| 文件 | 改什么 | 改成 |
| --- | --- | --- |
| `astro.config.mjs` | `export const SITE_URL` | `'https://liudelin.com'` |
| `src/data/profile.ts` | `site.url` | `'https://liudelin.com'` |
| `public/robots.txt` | `Sitemap:` 那行 | `https://liudelin.com/sitemap.xml` |

> 💡 不知道域名填什么也没关系 —— 先用 Vercel 分配的免费地址
> （形如 `xxx.vercel.app`），部署成功后再回来改成自己的域名，然后重新 push 一次。

## 第 1 步：把代码推到 GitHub

### 1.1 在 GitHub 上建一个空仓库

1. 打开 https://github.com/new
2. **Repository name** 填 `portfolio`（或你喜欢的名字）
3. **Public** 保持选中（公开仓库 Vercel 免费部署；私有仓库也可以，但公开更省事）
4. ⚠️ **不要勾选** "Add a README file"、"Add .gitignore"、"Choose a license"
   —— 仓库必须是空的，否则推送会冲突
5. 点 **Create repository**

### 1.2 在本地推送

打开 PowerShell，进到项目目录，执行（把 `你的用户名` 和 `仓库名` 换成实际值）：

```powershell
cd D:\dsWrokplace\front

git remote add origin https://github.com/你的用户名/portfolio.git
git push -u origin main
```

**首次推送会要求登录**，推荐用 Personal Access Token：

1. GitHub → 右上头像 → **Settings** → 左侧拉到底 **Developer settings**
2. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
3. Note 随便填，Expiration 选 90 天，勾选 **repo** 权限
4. 生成后**立刻复制**那串 token（只显示一次）
5. 回到 PowerShell，用户名填你的 GitHub 用户名，**密码粘贴那串 token**

推送成功后刷新 GitHub 页面，能看到你的文件。

## 第 2 步：用 Vercel 部署

### 2.1 注册 / 登录

1. 打开 https://vercel.com/signup
2. 选 **Continue with GitHub**（用 GitHub 账号一键登录，免注册）
3. 授权 Vercel 访问你的仓库

### 2.2 导入项目

1. 进入 https://vercel.com/new
2. 找到你刚推的 `portfolio` 仓库，点 **Import**
3. **配置项全部保持默认**，Vercel 会自动识别这是 Astro 项目：

   | 配置项 | 应该显示 |
   | --- | --- |
   | Framework Preset | `Astro` |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Install Command | `npm install` |

4. 点 **Deploy**，等 1-2 分钟

### 2.3 拿到网址

部署完成会给你一个地址，形如：

```
https://portfolio-abc123.vercel.app
```

**先把这个地址发到手机上用 4G 打开试试** —— 这就是你的网站在公网的真实速度。
如果国内 4G 打开很慢，先别急，后面「关于国内访问速度」那节有说明。

---

## 第 3 步：绑定你的阿里云域名

### 3.1 在 Vercel 添加域名

1. Vercel 项目 → **Settings** → **Domains**
2. 输入你的域名（例如 `liudelin.com`），点 **Add**
3. Vercel 会提示需要配置 DNS，**把这两条记录抄下来**：

   | Type | Name | Value |
   | --- | --- | --- |
   | A | `@` | `76.76.21.21` |
   | CNAME | `www` | `cname.vercel-dns.com` |

   > ⚠️ 具体数值以 Vercel 页面上显示的为准，不同时间可能不同。

### 3.2 在阿里云配置解析

1. 登录 https://dns.console.aliyun.com
2. 找到你的域名，点 **解析设置** → **添加记录**
3. 添加两条记录（对应上面抄的内容）：

   | 记录类型 | 主机记录 | 记录值 | TTL |
   | --- | --- | --- | --- |
   | A | `@` | `76.76.21.21` | 10 分钟 |
   | CNAME | `www` | `cname.vercel-dns.com` | 10 分钟 |

   > 主机记录 `@` 代表域名本身（`liudelin.com`），`www` 代表 `www.liudelin.com`。

4. 保存

### 3.3 等待生效

DNS 生效通常 **10 分钟到 2 小时**（偶尔要 24 小时）。回 Vercel 的 Domains 页面，
看到域名旁边出现绿色 ✅ 就成功了。

**HTTPS 证书 Vercel 会自动申请并续期，你不用管。**

### 3.4 回到第 0 步

域名生效后，把第 0 步那三个文件里的地址改成你的真实域名，然后：

```powershell
git add -A
git commit -m "更新站点地址为真实域名"
git push
```

Vercel 会自动重新部署，2 分钟后搜索引擎拿到的就是正确地址了。

## 以后怎么更新网站

**改文字内容**（最常见）：

```powershell
cd D:\dsWrokplace\front
# 修改 src/data/ 或 src/content/ 下的文件
git add -A
git commit -m "更新技能描述"
git push
```

推送后 Vercel 自动部署，约 1-2 分钟线上生效。**不需要做任何其他操作。**

**加新项目**：在 `src/content/projects/` 新建一个 `.md` 文件，然后照上面 push 即可。

**本地先看效果**：双击 `preview.ps1`，或执行 `npm run dev`。

## 关于国内访问速度（重要）

Vercel 的服务器在境外，国内访问**通常可用，但不保证秒开**。三种情况：

| 情况 | 建议 |
| --- | --- |
| 手机 4G 打开在 2 秒内 | 够用了，不用折腾 |
| 能打开但明显慢 | 可以接受 —— 面试官一般会等 |
| 打不开或极慢 | 考虑迁到国内云（见下） |

**迁到国内云需要备案**：域名必须 ICP 备案（免费，但审核 1-2 周，且必须有国内服务器）。
这是个不小的工程，**建议先用 Vercel 上线，等实际投递后看反馈再决定**。

> 说句实话：一个能打开的个人网站，比一个技术上更快但还没上线的网站价值高得多。
> **先上线，再优化。**

## 常见问题

### 部署失败，Vercel 报错

先看 Vercel 的 **Build Logs**。本地先执行一次确认能通过：

```powershell
npm run build
```

本地能过、线上不过，通常是 Node 版本差异。可以在 Vercel 项目
**Settings → General → Node.js Version** 里指定 `22.x`。

### 页面 404

Vercel 的 **Output Directory** 必须是 `dist`。
如果被改过，去 **Settings → Build & Development Settings** 改回来。

### 改了域名但网站还是旧的

1. 确认 `git push` 成功了（GitHub 页面上能看到最新提交）
2. 去 Vercel 项目的 **Deployments** 看最新一次部署是否成功
3. 强制刷新浏览器：`Ctrl + F5`

### 简历 PDF 点了 404

检查 `public/` 目录下 PDF 的**文件名**是否和 `src/data/profile.ts` 里
`contact.resumeFile` 写的一致（中文文件名要完全一致，包括全角括号等标点）。

### 想换简历 PDF

把新 PDF 放进 `public/`，然后改 `src/data/profile.ts` 的 `resumeFile` 指向新文件名，
push 即可。旧 PDF 可以留在目录里也可以删掉。
